# 验收与回滚方案

## 正确性门槛

- 已审核 benchmark 上，身份解析准确率不低于旧链路；CAS 明确且一致的单一物质目标 ≥99.5%。
- 所有 CAS/名称冲突、多个候选身份和混合物组成不完整的记录必须人工复核。
- 高风险类别召回率必须为 100%；样本量不足时不能用百分比掩盖遗漏，逐条列出结果。
- 自动建议与旧链路不一致时必须输出结构化差异原因，不允许只比较最终类别。
- `false`、`unknown`、`not_applicable` 不得混用。
- 没有外部证据引用的 LLM 结果不能进入自动审批证据集。

## 性能门槛

先以阶段 0 实测基线为准，目标门槛如下：

- 本地身份/证据缓存命中：单条 P95 ≤100 ms。
- 20 条页面且大部分缓存命中：enrichment P95 ≤3 秒。
- 20 条未缓存但可被 PubChem 解析的页面：查询阶段 P50 ≤15 秒、P95 ≤30 秒。
- 整页 LLM 调用数相对待处理试剂数 ≤20%，且单一 identity 最多一次正常抽取调用。
- 全链路 20 条页面 P95 ≤60 秒；达到预算后必须有界结束，不能出现无限重试。
- 503 注入时首次失败后的额外阻塞 ≤10 秒，熔断期间不再发起同步请求。

## 业务效果门槛

- 自动建议错误率不得高于旧链路。
- 在错误率不升高的前提下，人工复核率相对旧链路下降至少 20%；若样本结构变化，必须使用相同 benchmark 对比。
- 数据源不可用时，已缓存的低风险/高风险结果按策略降级，未缓存项目可解释地进入人工复核。
- ERP 写入候选必须继续满足现有最小置信度和写入安全检查。

## 必测场景

1. 中文规范名、英文名、分子式、CAS、名称带 CAS。
2. 名称带纯度、浓度、等级、包装、供应商、货号。
3. ERP CAS 格式错误、校验位错误、CAS 与名称冲突。
4. 盐、溶剂化物、水合物、同位素、立体异构体、多组分混合物。
5. 叠氮、高氯酸浓度边界、汞、重金属、氧化剂、易燃液体、毒性阈值边界。
6. PubChem 404、429、503、超时、返回多个 CID、返回名称不一致。
7. CompTox 未配置 key、无权限、限流和成功批量响应。
8. NIST 无记录或只有部分字段。
9. LLM 无 key、超时、非法 JSON、幻觉字段、证据 span 不存在。
10. 缓存命中、过期、stale-if-error、schema 升级和并发 single-flight。

## 影子运行报告

每天至少输出：

- 新旧链路处理数量、总耗时、P50/P90/P95。
- provider 请求、成功、404、429、5xx、超时、熔断和平均耗时。
- 身份 verified/ambiguous/conflict/unresolved 比例。
- 各字段覆盖率、冲突率和来源分布。
- LLM 调用率、失败率、平均耗时和触发原因。
- 最终类别一致率、差异样本、人工复核率和高风险遗漏数。

## 回滚条件

出现任一条件立即将 `enrichment_v2.enabled` 设为 false：

- 任一已确认高风险样本被新链路判成更低风险且未进入人工复核。
- 自动建议错误率显著高于旧链路。
- P95 超过旧链路且持续两个批次，或批次无法在总预算内结束。
- 证据引用丢失、缓存身份串用、规则版本无法追溯。
- ERP 写入行为受到非预期影响。

回滚只切换编排入口。新缓存使用独立 schema/version，不覆盖旧缓存；shadow mode 不写 ERP，因此无需数据回滚。
