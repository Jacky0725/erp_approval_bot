# 分阶段任务与执行提示词

顺序：P0 → P1 → P2 → P3 → P4 → P5。P3 的只读证据采集可在 P0 后提前；P4 不依赖无关的大规模后端整理。用户单独选择 UI 时只做 P0、P3、P4 和相关 P5。默认单任务推进，不要求多代理并行。

## P0：保护当前工作并建立基线

**执行提示词：**

> 检查本包快照与当前代码的差异。记录当前 Git 状态、源文件哈希、API 方法/路径/参数/返回、八页模板 ID/name 和静态资源清单。检查现有测试是否触发外部服务；先运行安全的相关测试，再在证明隔离后建立全量非 ERP 基线。用临时目录和合成数据建立无外部写入的 UI 预览/测试入口，替换调度器、钉钉、worker、更新、记忆同步及 ERP 行为，保留生产 app 导出。不要修改真实配置。记录测试隔离边界，创建 BASELINE.md 和契约证据。

**完成标准：** 已知用户改动受保护；可重复执行的隔离实例；后台调用被禁止且有测试证据；原有测试失败有记录。API 清单需包含参数/响应，自动正则清单仅作起点。

## P1：安全与数据可靠性

**执行提示词：**

> 跟踪 normalize_write_result 在 approval_flow/approval_writer 的调用和旧实现语义，区分 None、缺省 handled、空 handled、部分失败、deferred 与重试耗尽。先添加失败场景测试，确认何处确实将未知当成功。提出最小兼容修复；语义改变先形成具体草案等待确认。检查 Excel 输出锁定、并发命名、异常中断，复核队列与记忆库写入部分成功，以及审计记录能否关联决定和实际结果。只修复有证据的问题，不迁移生产数据、不改变规则分类。

**完成标准：** 关键边界有测试；无重复提交或未知成功的未解释路径；持久化失败有恢复/诊断；任何语义变更单列。未确认的语义调整不阻塞纯兼容工作。

## P2：模块整理与 V2 整合

**执行提示词：**

> 基于调用关系确定 web_runner、approval_flow、chemical_searcher 的实际重复和职责混杂。按纯函数→内部服务→入口适配的小批次整理，保留旧入口和调用约定。复用现有任务互斥、批次状态、证据/身份模块；不另建新补全引擎，不移除旧链路。每次抽取运行对应测试，检查错误传播、日志关联及打包资源。没有必要的抽象不新增。

**完成标准：** 原行为/接口一致；旧导入可用；V2 状态未被意外改变；新增文件的职责有明确理由。不得以行数减少作为唯一成果。

## P3：UI 基线与设计审查

**执行提示词：**

> 读取 Product Design audit 及其前置 skills，按其浏览器要求打开 P0 隔离实例。使用当前合成数据捕获八页桌面和窄屏状态，逐张检查；为运行、建议、复核和设置建立任务路径。区分已观察问题与候选改进，记录页面、截图、操作、影响及优先级。将方案限制在现有导航、布局目标和设计 tokens 内，先提出具体前后对照。不是全新视觉设计时不要强行启动 ideate/Figma。输出 UI_AUDIT.md、截图和实现清单。

**完成标准：** 截图可读且与本次实例相符；高优先级问题对应证据；布局/交互范围可评审。浏览器无法验证时记录缺口，不把本阶段标为通过。

## P4：Web UI 实施

**执行提示词：**

> 按 03_WEB_UI_PLAN.md 和 P3 证据实施。先整理统一请求与错误处理、状态防重入、乱序保护和修改请求防重复；再改善运行/建议/复核，最后一致化其余五页。保留 ID/name、API、已有 dirty/edit 保护和安全门控。复用 CSS token，合并有证据的覆盖规则，修复实际窄屏裁切。引入内部 JS 模块时验证加载顺序、缓存版本和打包。使用合成数据注入慢响应、非 JSON、失败、空数据和长文本；逐页验证并保存前后截图。

**完成标准：** 原有操作可用；慢请求最多一条状态请求在途；旧筛选结果不覆盖新状态；编辑内容保留；修改请求不自动重试；无新增控制台/资源错误；桌面和窄屏验证完成。

## P5：回归、打包与交付

**执行提示词：**

> 运行 06_ACCEPTANCE_AND_ROLLBACK.md 的相关矩阵和已隔离的全量非 ERP 测试。检查源码启动和 Windows 打包资源引用，对新增 static/template 文件证明会进入安装包；条件允许时使用临时构建输出验证，不覆盖正式发行物。整理 README、配置兼容说明和回退步骤。核对 diff 无无关改动、凭证或业务数据。真实 ERP 冒烟未授权则明确未执行。更新实施状态，交付真实结果与剩余风险。

**完成标准：** 无未解释回归；必要 UI/打包证据齐全；不能执行的检查单列；存在受阻项时交付可用部分并明确整体未完成。
