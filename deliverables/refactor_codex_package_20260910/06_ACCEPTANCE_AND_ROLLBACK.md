# 验收与回退

## 安全运行前提

测试使用临时目录与合成清单，不复制真实 SQLite、Excel、日志或 .env。预览启动前替换所有后台触发器；浏览器只连接本地隔离实例。禁止自动安装更新、同步真实记忆库、启动钉钉监听或访问 ERP。

pytest.ini 默认排除 erp_smoke，但这不等于所有其他测试都没有副作用；全量运行前检查实际测试内容和 fixture。导入模块也可能初始化全局对象，必须核验。

## 最小矩阵

| 领域 | 必测场景 | 通过条件 |
| --- | --- | --- |
| 规则 | 现有分类与高风险边界、未知/冲突、候选不晋升 | 未授权分类变化为零 |
| 写入 | None/缺省/空/部分成功/失败/deferred/超时重读/重试耗尽 | 决策与执行结果不混淆，不凭未知宣称保存 |
| 运行 | 双击启动、已有任务、停止请求、崩溃残留、状态恢复 | 无第二个意外 worker；状态与日志一致 |
| 导出 | 锁定、同秒并发、写中异常 | 原文件可保全，真实产物路径正确，失败可追踪 |
| 复核 | 分页筛选、LLM 辅助、编辑刷新、部分保存失败 | 不误确认，不丢输入，不隐藏失败 |
| API | 原路径/方法/参数/返回、错误、下载边界、配置门控 | 无破坏性变化；有用例证明 |
| V2 | enabled/shadow、无样本、provider 失败和未知证据 | 不接管生产，不伪造统计 |
| UI 请求 | 慢响应、掉线、500、非 JSON、乱序、恢复 | 明确过期/错误；无重叠状态轮询/错误覆盖 |
| UI 布局 | 八页桌面/390px、重点页360px/缩放、长表格 | 控件可达，页面无裁切，表格内部滚动 |
| 无障碍 | 键盘、焦点、label、状态文字、尺寸与对比 | 记录检查范围，不宣称全站合规 |
| 安装包 | 旧入口、template/static、版本缓存、源码/冻结路径 | 资源全，原启动方式可用 |

## 本轮已执行的基线命令

```powershell
python -m pytest tests/test_approval_batch_state.py tests/test_web_review_confirmation.py tests/test_web_runner_workflow.py tests/test_web_data_health.py tests/test_web_enrichment_shadow.py -q
```

结果：64 passed in 4.28s，退出码 0。仅覆盖所列范围；不是全量验收，不包含浏览器和 ERP。

未来全量候选命令：先完成隔离检查，再执行 `python -m pytest -q`，保留原始结果。不要自动添加强制覆盖错误的选项。

## 测量与完成条件

- 正确性优先：原始行为基线没有未批准变化；已有失败与新增失败区分。
- UI 性能在同一合成数据、机器、窗口尺寸下记录前后请求数量/在途数和耗时；没有基线不承诺速度比例。
- 每阶段需可重现的测试结果和变更清单；P3/P4 需截图与交互/控制台记录，截图仅证明相应状态。
- 不因单项测试通过跳过安装包资源验证，也不为低风险纯文档改动增加业务测试。

## 回退

1. 每阶段开始记录受影响文件哈希和已存在改动。备份只放本地私有位置，避免把用户配置差异装入交付 ZIP。
2. 代码回退以该阶段实际补丁为单位，先预览反向差异；用户继续编辑过的文件人工合并，不用整个仓库回滚。
3. 本包不修改生产数据，因此不提供会误执行的恢复脚本。未来持久化改变必须先创建可校验备份和恢复演练，再批准上线。
4. 若涉及配置扩展，回退时仅撤销本阶段新增项，保留用户原值；不要直接覆盖 settings.yaml 或 .env。
5. UI 回退保持 JS/CSS/template 同版本；安装包回到上一已验证版本，不让旧模板加载新脚本。
6. V2 独立保持原开关和旧链路；本轮不借回退名义切换业务模式。
