## 测试与升批原则

- 30、40、50、100条组批和结果导入往返已用隔离客户端验证；越界配置、超额结果行被拒绝。
- 软件测试通过不代表模型在40/50/100条已稳定，当前不自动升批。
- 先以30条检查模型交接，再用新增的30条真实未匹配待办验证ERP保存及入库；连续几批稳定、每条平均耗时降低后，才考虑40、50条。100条暂不作为正式目标。
- 原15分钟结果等待限制保留，不为通过测试而直接放宽。错误、超时或缺失记录均保留原批次，不自动重发。
